# MEss

Full-stack web application built with React and Node.js.

## Tech Stack

- **Frontend**: React
- **Backend**: Node.js / Express
- **Database**: Supabase (PostgreSQL)
- **Hosting**: Render

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```
